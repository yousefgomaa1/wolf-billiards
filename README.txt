WOLF BILLIARDS — Physics Lab (prototype 0.1)

Run:
1) Extract this folder.
2) Open the folder in Visual Studio Code.
3) Open index.html in a browser (double-click it), or use the VS Code Live Server extension if already installed.

No Flutter, Node.js, or Android SDK is required for this first browser prototype.

Current scope:
- Independent 2D pool-table simulation.
- Cue direction selection by dragging on the table.
- Adjustable shot power.
- Basic ball-to-ball collision, rail bounce, and friction approximation.

Limitations:
- Educational prototype, not a validated tournament-grade physics engine.
- No spin, pockets/ball removal, cushion calibration, or multi-collision prediction preview yet.
- It does not read, overlay, or interact with any third-party game.
